# Family Points has moved

The app now lives in its own repository and is served from the root of the
site, so the address is short enough to hand to a family:

**https://nimrodf8.github.io/** — source: https://github.com/nimrodf8/nimrodf8.github.io

What is left in this folder is a redirect, so that bookmarks and — more
importantly — invite links made before the move still work. An invite carries
the family in the address fragment (`#join=…`), and the redirect passes that
along rather than dropping it.

Nothing was lost in the move: it is the same domain, so every browser that
already held a family, a sign-in or a sync connection still holds it at the new
address. The full history of the app up to the move is in this repository's git
history.
